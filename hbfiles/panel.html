Configura la cifratura

È il primo accesso. Scegli una password di cifratura: proteggerà i tuoi file. Il server non la conosce mai.

Importante: questa password non è recuperabile dal server. Se la dimentichi, potrai rientrare solo con la recovery key che stai per ricevere.

La tua recovery key

Salvala ORA in un posto sicuro. È l'unico modo per rientrare se dimentichi la password.

Se perdi sia la password sia questa recovery key, i tuoi file saranno persi per sempre. Nessuno — nemmeno gli amministratori — può recuperarli. È il prezzo della sovranità: solo tu hai le chiavi.

Inserisci la recovery key e scegli una nuova password.
